function getRandomInt(min, max) {
    return Math.floor(Math.random() * (max - min + 1) + min);
}

Due to hoisting we can call the function before it is declared. As the default Javascript behavior is to move declarations to the top.

Arrow function

We can write the same function as an arrow function:
const getRandomIntArrowFunction = (min, max) => {
    return Math.floor(Math.random() * (max - min + 1) + min);
};

Call-back functions

A function reference provided as an argument with the posibility (perhaps) of being called Example:
function getRandomIntCallBackFunction(min, max, randomIntFunction) {
    return randomIntFunction(min,max);
}
console.log(getRandomIntCallBackFunction(5,10,getRandomInt));
