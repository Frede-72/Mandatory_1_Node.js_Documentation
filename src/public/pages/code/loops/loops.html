LOOPS

Rules

1. Use loop methods in javascript
2. Only use for-loops for finger counting
3. Use .map if data is needed after. Only use .foreach if not

Methods

.map .filter .reduce .find .findIndex .indexOf ( .forEach )

Why loop methods

Shorter and more readable code. Gives more information about what we want to do.
Avoids out of bounds errors and for of/in confusion.
Both element and index can be accessed at the same time.
We don't mutate the original list
Example:
const numbers = [1,2,3,4,5];

const doubleNumber = numbers.map((number) => number * 2);
console.log(doubleNumber);
console.log(numbers);
[ 2, 4, 6, 8, 10 ]
[ 1, 2, 3, 4, 5 ]
