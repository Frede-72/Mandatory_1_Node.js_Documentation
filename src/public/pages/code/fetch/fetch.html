FETCH

To make a fetch request to our API and show the result in a h3 element with id counter:
app.get("/api/counter" , (req, res) => {
    res.send({ data: ++counter });
});
We can write in a script in index.html:
fetch("/api/counter")
.then((response) => response.json())
.then((result) => {
    const counterH3 = document.getElementById("counter");
    counterH3.textContent = result.data;
});
