DATA TYPES

There are 8 data types in javascript - Number, Bigint, String, Boolean, Undefined, Null, Symbol, Object

Type coercion - implicit conversions

We want to avoid these as they can behave not as intended Example:
const number = 10;
const number2 = "5";

console.log(number + number2);
105
Instead do:
const sum = number + Number(number2);
console.log(sum);
15
