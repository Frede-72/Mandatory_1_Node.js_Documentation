DATE

We can create a new Date object with:
const date = new Date();

Using for example .getMonth and .getDay you get a number return.
(Example made monday 19. october 2026)
console.log(date.getMonth(), date.getDay());
9 1
9 refers to the 10th month october, as it is zero-indexed. 1 is monday as 0 is sunday.

To get the month and day as text we can use .toLocaleString
console.log(date.toLocaleString("en-uk", {month: "long" , weekday: "long"}));
October Monday
