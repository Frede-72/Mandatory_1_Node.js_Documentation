GIT

Init

Git is a version control system. The command:
$ git init
Initialized empty Git repository in {Current_path}
Initializes git in the folder we are in. A hidden folder .git is created inside the project for tracking

Commit - push

First use the command:
$ git add {File_name}
To stage the file or
$ git add -A
To stage all changes. The staged changes is what will be in the next commit.
To commit the changes use:
$ git commit -m "Message"
-m adds the commit message.
If you have a github repository use:
$ git push
To push the commit to github

Branch

To create a new branch use:
$ git branch {Branch_name}
And to switch between branches:
$ git checkout {Branch_name}
The command:
$ git status
Can be used to see the current branch, staged or non-staged changes and untracked files
