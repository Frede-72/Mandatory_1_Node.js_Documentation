NODEMON

Nodemon restarts the application any time a change is made.
This helps avoid having to type node {File_name} all the time. To install use the command:
$ npm install -g nodemon

And then run your application with:
$ nodemon {File_name}

Nodemon.json

By default nodemon does not restart on changes to html and css.
If we want that we can make a file called nodemon.js. Here we can add:
{
"ext": "js,mjs,cjs,json,css,html"
}
To specify the file types we want to have nodemon restart the application when changed.
