NODE.JS

Node.js makes it possible to run javascript outside of the browser.
Node.js can be downloaded here: https://nodejs.org/en/download
To run a file with node use the command:
$ node {File_name}

Node modules

The node_modules folder is where our third-party dependencies are stored.
We don't want to push the node_modules folder. Instead the package.json file tells what dependencies we use.
To install these dependencies we use npm.
$ npm install

CommonJS vs ES modules

CommonJS loads synchronous while ES modules loads asynchronous
By default Node.js uses CommonJS. It can be changed by adding
"type": "module"
To package.json

import export

CommonJS uses require and module.exports
ES modules uses import and export
