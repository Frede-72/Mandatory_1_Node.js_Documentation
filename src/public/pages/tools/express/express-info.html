EXPRESS

A server with express (ES module):
import express from "express";
const app = express("public");

app.use(express.json());

const PORT = 8080;

app.listen(PORT, error => {
    if(error) {
        console.log(error);
    }
    console.log("Server running on port: " , PORT);
});
express.json() allows us to parse the json in requests.
To send data with GET requests we can do:
app.get('/', (req, res) => {
    res.send({ data: "Hello" });
});
This displays { data: "Hello" } on the "/" endpoint
To serve static files we can add:
app.use(express.static("public"));
public means only files in the public folder can be accessed
