REST API

The 5 HTTP-verbs we use are:
GET - Retrieve the resource(s)
POST - Create a new resource
PUT - Replace existing resource with another resource
PATCH - Replace parts of existing resource
DELETE - Delete resource

In this order. For naming we want to use a noun in plural form.

Example:

app.get('/animals', (req, res) => { res.send() });

app.get('/animals/:id', (req, res) => { res.send() });

app.post('/animals' , (req, res) => { res.send() });

app.put('/animals/:id', (req, res) => { res.send() });

app.patch('/animals/:id', (req, res) => { res.send() });

app.delete('/animals/:id', (req, res) => { res.send() });
